# コピーライティング・文章生成プロンプト
# 用途: キャッチコピー・サービス紹介文・各セクションの文章をAIに生成させるときに使う
# 使い方: このファイルを開いて「依頼内容」を書き換えてClaudeに貼り付ける

---

## 私の情報（固定）

| 項目 | 内容 |
|---|---|
| 屋号 | KENT DESIGN OFFICE |
| キャッチコピー（確定） | テクノロジーで、仕事をもっとラクに。 |
| サブコピー（確定） | Web制作・業務改善・アプリ開発で、ビジネスを次のステージへ。 |
| サービス | Web制作 / 業務改善・効率化 / 人材派遣 |
| ターゲット | Web制作・業務改善を検討している中小企業経営者・個人事業主 |
| サイトの目的 | 個人ブランディング・実績紹介・仕事依頼獲得 |
| 雰囲気 | スタートアップ・テック系・さわやかオフィス |
| カラー | ベース #FFFFFF / サブ背景 #F4F6F9 / プライマリ #185FA5 / アクセント #378ADD |

## ページ構成（確定）

| セクション | 内容 |
|---|---|
| Hero | キャッチコピー + CTA + オフィス画像 |
| Services | Web制作 / 業務改善・効率化 / 人材派遣 |
| Stats | 実績数値（年数・案件数・対応エリア） |
| About | 自己紹介 + スキルタグ |
| Works | 制作実績（PLANET・配送日報アプリ・YouTube自動通知など） |
| Contact | 問い合わせCTA |

## 依頼内容（ここを毎回書き換える）

```
あなたはコピーライティングの専門家です。
上記の「私の情報」を前提に、以下を作成してください。

【依頼】
（ここに具体的な依頼を書く）

例：
- Servicesセクションの各サービス説明文（1サービスあたり50字以内）を3案ずつ
- Aboutセクションの自己紹介文（150字）を2案
- ContactセクションのCTAボタン文言を5案
- Statsセクションに載せる実績の切り口を5案

【トーン】
- 堅すぎず、軽すぎない
- テクノロジーへの親しみやすさを感じさせる
- 信頼感・専門性が伝わる

各案には選んだ理由を一言添えてください。
```
